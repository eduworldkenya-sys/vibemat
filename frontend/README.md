# VibeMat mobile frontend

Expo + React Native + TypeScript frontend foundation for Android and iOS.

## Run locally

```bash
npm install
npx expo start
```

Day 1 surfaces: Home feed, Pulse, Explore/map preview, place following, Create/media picker, Communities, Profile, Inbox and mobile navigation. Backend-dependent actions must be labelled as pending integration. Demo content and map previews are fixtures, not live information.
